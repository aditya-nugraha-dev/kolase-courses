CARA 1 (disarankan): plugin html.to.design — hasil bisa diedit
----------------------------------------------------------------
1) Daftar/buka Figma (figma.com) -> New design file.
2) Menu Resources/Plugins -> cari "html.to.design" -> Run.
3) Paste URL halaman website (daftar URL di bawah) -> Import.
   Atur viewport: 390x844 untuk HP, 1440x900 untuk desktop.
4) Ulangi per layar -> susun frame per halaman (HP + desktop).
5) Font Hammersmith One: Figma minta install font ke laptop
   sekali (Google Fonts, gratis) agar judul tampil sama persis.
Catatan: paket gratis plugin ada batas impor per bulan —
prioritaskan 6 layar bertanda [utama] di bawah. Alternatif
gratis tanpa batas: screenshot (Shift+Win+S) -> paste langsung
di Figma sebagai gambar referensi (tidak bisa diedit).

CARA TERMUDAH (mode demo 1-klik, tanpa daftar):
Buka login.html?demo=1 (tambah ?demo=1 di URL, atau klik
"Coba mode demo" di halaman login) -> otomatis masuk sebagai
murid contoh berisi penuh: trial 7/7, paket lunas + badge +
sertifikat, placement, evaluasi guru, chat, pengumuman.
Lalu import halaman apa pun — semuanya terisi, bukan kosong.
Isi chat/ulasan/transaksi contoh: buat dulu 1 akun murid +
1 trial di website, baru import dashboard-nya.

CARA LOKAL (desain dari VS Code, bukan dari website live)
---------------------------------------------------------
Kalau yang di-import mau dari kode di laptop (bukan yang sudah
di-push), jalankan websitenya secara lokal dulu:
1) VS Code -> Extensions -> cari "Live Server" (Ritwick Dey)
   -> Install.
2) File -> Open Folder -> pilih folder kolase-static.
3) Klik kanan home.html -> "Open with Live Server". Chrome
   terbuka, catat portnya (biasanya 5500).
4) Di tab Chrome itu: daftar 1 akun murid + 1 trial agar
   dashboard ada isinya (data tersimpan di browser itu).
5) Di plugin html.to.design: paste URL lokal, contoh:
   http://127.0.0.1:5500/home.html -> Import seperti biasa.
   Ganti home.html dengan nama file lain untuk layar lain.
6) Tiap ubah kode -> simpan -> browser reload otomatis ->
   import ulang halaman itu.
Catatan jujur:
- Kalau plugin menolak alamat localhost, pakai URL live
  GitHub Pages saja (kodenya sama persis yang sudah di-push),
  atau screenshot halaman lokal (Shift+Win+S) lalu paste di Figma.
- Aset gambar/logo: drag langsung dari folder
  kolase-static/assets/ ke kanvas Figma.
- Login: plugin membaca sesi Chrome yang sama — login dulu
  di tab localhost sebelum import dashboard/portal.

BATAS JUJUR
------------
- Hasil import = potret diam; ubahan di Figma TIDAK mengubah
  website (dan sebaliknya). Untuk ubah tampilan, tetap edit kode.
- Data dinamis (nama murid, saldo) ikut terpotret apa adanya.
- Ikon/logo: unduh dari kolase-static/assets/ untuk dipasang
  manual bila hasil import pecah.
